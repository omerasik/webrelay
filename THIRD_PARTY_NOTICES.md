# Third-party notices

WebRelay implements its own restricted templates, durable scheduler, authorization, evidence storage and dashboard. [Browser Use](https://github.com/browser-use/browser-use) was a conceptual reference for browser automation; it is not a dependency of this application.

The application uses [Playwright](https://github.com/microsoft/playwright-python), its installed Chromium distribution, [FastAPI](https://github.com/fastapi/fastapi), [Pydantic](https://github.com/pydantic/pydantic) and Uvicorn. Those distributions retain their own copyright and license materials, including browser notices. Preserve those materials when redistributing dependencies.
